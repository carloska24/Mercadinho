# CAIXA MERCADO — NOVO PROJETO

## Objetivo
Criar do zero um **PDV desktop profissional para Windows**, com comportamento de software empresarial de varejo.

## Stack oficial
- C#
- .NET 10 LTS
- WPF
- XAML
- MVVM
- ASP.NET Core para API quando necessário
- PostgreSQL
- Entity Framework Core
- OpenAPI
- Git

WPF é uma tecnologia de UI para Windows baseada em .NET, com XAML, controles, data binding, layout, estilos, templates, janelas e comandos. O WPF é Windows-only.

## Filosofia
Não construir um dashboard SaaS. Construir um **software de frente de caixa**.

A prioridade é:
1. produtividade;
2. velocidade;
3. clareza;
4. confiabilidade;
5. estética.

## Primeira meta
Abrir um aplicativo WPF contendo:
- header;
- menu;
- campo EAN/PLU;
- grid de itens;
- resumo;
- total;
- atalhos;
- status do caixa.

Antes de implementar tudo, leia todos os `.md` deste projeto e apresente um plano.
