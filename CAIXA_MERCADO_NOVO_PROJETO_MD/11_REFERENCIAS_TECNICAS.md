## Microsoft — WPF
WPF é uma tecnologia de UI para Windows no .NET, com XAML, controles, data binding, layout, estilos e templates.

https://learn.microsoft.com/pt-br/dotnet/desktop/wpf/overview/

ASP.NET Core fornece APIs Web com Controllers ou Minimal APIs. A documentação atual recomenda Minimal APIs para novos projetos quando apropriado.

https://learn.microsoft.com/pt-br/aspnet/core/fundamentals/apis?view=aspnetcore-10.0
